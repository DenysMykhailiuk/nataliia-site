# MapEmbed

The 4:3 map frame above `OfficeCard`. Lazy-loaded, with a sand placeholder behind it so the
space never flashes white.

```jsx
<MapEmbed title="Кабінет на Берестейському проспекті, 90а" />
```

`title` is required for screen readers — describe the place, not the map.
