# ServiceList

The service rows stacked 48px apart. Alternate `reverse` on every second `ServiceRow` so
the photographs zig-zag down the page.

```jsx
<ServiceList>
  <ServiceRow />
  <ServiceRow reverse number="02" title="Сімейна терапія" price="1900 грн" />
  <ServiceRow number="03" title="Групова терапія" price="2400 грн" />
</ServiceList>
```
