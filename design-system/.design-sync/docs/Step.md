# Step

One numbered step of the first-meeting explainer: a serif clay numeral, a sans `h3` — the
one place headings are not serif — and a muted paragraph. No card and no rule.

```jsx
<Step number="03" title="Перша сесія — 60 хвилин">
  Знайомимось, ви розповідаєте свою історію в комфортному для вас темпі.
</Step>
```
