# InlineLink

A text link with a hairline underline — the site’s "read more" affordance, used at the end
of a block rather than inside a sentence.

```jsx
<InlineLink href="/practice/">Докладніше про мою діяльність</InlineLink>
```

Pass `onDark` on the testimonial band, where the text and underline both go light.
