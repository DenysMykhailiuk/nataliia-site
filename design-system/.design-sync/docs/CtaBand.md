# CtaBand

The centred sand band that closes every page with an invitation to write. One heading,
one sentence held to a 54-character measure, and a centred `ButtonRow`.

```jsx
<CtaBand title="Готові почати?" spaced>
  Напишіть мені — домовимось про зручний час і формат.
</CtaBand>
```

`spaced` adds 70px above, for when the band follows a flush section.
