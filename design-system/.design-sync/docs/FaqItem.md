# FaqItem

One collapsible question, built on native `details`. Lives in the footer’s third column,
which supplies the rules between items and the muted answer type.

```jsx
<FaqItem question="Чи працюєте ви з підлітками?">Так, з підлітками від 14 років.</FaqItem>
```

Pass `open` to render a question already expanded; the footer leaves all three closed.

The same three questions are also published as FAQ structured data on the homepage — keep
the wording in step.
