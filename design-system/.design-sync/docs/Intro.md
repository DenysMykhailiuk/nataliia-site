# Intro

The opening block of an inner page — `h1` plus a couple of paragraphs, held to 720px. Goes
inside a `tight` section; the homepage uses `Hero` instead.

```jsx
<Section spacing="tight">
  <Intro title="Три формати роботи">
    <Lede>Індивідуальні та сімейні сесії проходять у кабінеті або відеодзвінком.</Lede>
  </Intro>
</Section>
```
