# Quote

A short testimonial for the dark band: serif italic in guillemets, with first name and
age below. Always inside `QuoteWall` — on a light background it renders as dark-on-light
text that was never designed for it.

```jsx
<Quote attribution="Катерина, 28 років">«Тривога не зникла за один день…»</Quote>
```

Client words are verbatim. Long testimonials belong in `ReviewCard` instead.
